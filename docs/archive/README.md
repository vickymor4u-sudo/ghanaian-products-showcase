# Archived planning documents

Status: **Historical reference only. Not authoritative.**

The files in this folder are pre-`docs/` scratch and planning artifacts from
early site development. They are retained for institutional memory but must
not be used to guide implementation, business rules, or public content.

`docs/BORGAFOODS_CONTEXT.md`, `docs/BUSINESS_RULES.md`, and the other files
directly under `docs/` are the authoritative sources per
[`../AI_TASK_PROTOCOL.md`](../AI_TASK_PROTOCOL.md). Where anything here
conflicts with current `docs/` content — for example, looser private-label
language in `CATALOG_EXTRACTED_INFO.md` that predates the narrow,
`fufu-borga`-only approval in `PRODUCT_CAPABILITY_MODEL.md` — the current
`docs/` files govern.

- `BUSINESS_INFO_CAPTURE.md`, `CATALOG_EXTRACTED_INFO.md`,
  `COMPLETE_COMPANY_INFO.md`, `WEBSITE_REQUIREMENTS.md`, `ideas.md`: raw
  source material used to compile the current `docs/` knowledge base.
- `CONTRAST_ISSUES.md`: an accessibility issue log. The homepage "Our
  Mission" contrast issue it describes has since been fixed (the section now
  uses light text on the primary background); the remaining "sections to
  check" items were not independently re-verified during archiving.
